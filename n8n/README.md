# n8n — ما يُولَّد من هذا المستودع ويُلصَق في الأتمتة

بوت واتساب (`BP-WhatsApp-Main` → عقدة `Build Menu Response`) يعرض قائمة
الخدمات. كانت القائمة مكتوبة بيد داخل العقدة، فانحرفت: ٥٦ خدمة من ١٤٠ فقط
كانت تصل العميل على واتساب، و٨٤ خدمة يبيعها الموقع لم تكن موجودة في القائمة
أصلاً — منها قسما العقارات والأتمتة كاملين.

قائمة تُكتب بيد ستنحرف دائماً. لذلك تُولَّد من الكتالوج هنا:

| الملف | ما هو |
|---|---|
| `wa-menu-data.js` | ثوابت `CATS` و`SVCS` مولّدة من `site/assets/data/catalog.json` |
| `wa-build-menu-response.js` | كود عقدة `Build Menu Response` كاملاً وجاهزاً للّصق |

```bash
npm run wa:menu     # يولّد wa-menu-data.js من الكتالوج
npm run wa:check    # يفشل إن كان الملف قديماً — يعمل ضمن npm run build
```

`npm run build` يعيد التوليد تلقائياً، فأي خدمة تُضاف إلى الكتالوج تظهر في
الفرق عند المراجعة بدل أن تختفي بصمت.

## التحديث على n8n

انسخ `wa-build-menu-response.js` كاملاً والصقه في العقدة
`Build Menu Response` داخل `BP-WhatsApp-Main`. n8n يحتفظ بتاريخ النسخ، فالتراجع
عودة إلى النسخة السابقة من `Workflow history`.

## حدود واتساب التي يراعيها الكود

- القائمة التفاعلية **١٠ صفوف كحد أقصى**؛ لذا ٦ خدمات في الصفحة + «التالي» +
  «السابق» + «كل خدمات القسم» + «القائمة الرئيسية» = ١٠ بالضبط.
- عنوان الصف **٢٤ حرفاً**، والوصف **٧٢ حرفاً** — `cut()` يقصّهما.
- التنقّل بين صفحات القسم عبر المعرّف `catp_<slug>_<page>`.

# بوابة الوكيل — من يردّ، الآلة أم إنسان؟

الملف: `wa-agent-gate.js` (عقدة Code باسم **Agent Gate**).

الوكيل يردّ على كل رسالة. حين يمسك موظف محادثة — عميل غاضب، صفقة تُقفل
بالكلام، حالة خاصة — فردٌّ آلي في وسط الكلام يفسدها. البوابة تسمح لفريق
العمليات بإسكات الوكيل من `/ops ← واتساب`:

- **الوكيل كله**: زر واحد يوقف الردّ الآلي على الجميع.
- **رقم واحد**: يُوقَف تلقائياً ساعةً بمجرّد أن يرسل الفريق رسالة من اللوحة،
  ويعود بنفسه بعدها — لا أحد مطالَبٌ بتذكّر إعادة تشغيله.
- **إيقاف مؤقّت**: ٣٠ دقيقة / ساعة / ٤ ساعات / يوم، بعدها يعود وحده.

الحالة في جدول `wa_agent_gate` (انظر `db/schema.sql`). **لا صفّ = يردّ**،
وكذلك يفعل عند أي عطل: البوابة تحرس المحادثة ولا تُسقط الخدمة.

## التركيب على n8n

1. أضف متغيّر البيئة `BP_PANEL_KEY` في n8n — نفس مفتاح لوحة `/ops`.
2. أنشئ عقدة **Code** باسم `Agent Gate` والصق فيها `wa-agent-gate.js`.
3. ضعها بعد استقبال الرسالة وقبل أوّل عقدة تردّ.
4. بعدها عقدة **IF** على `{{ $json.agentPaused }}`:
   - `true` → لا شيء (يتوقّف المسار — الموظف يردّ من اللوحة).
   - `false` → بقيّة المسار كما هو.

الفحص من الطرفية:

```bash
curl -s https://www.businesspartner.sa/api/simple \
  -H 'content-type: application/json' \
  -d '{"action":"ops-wa-check","key":"<مفتاح اللوحة>","phone":"9665XXXXXXXX"}'
# {"ok":true,"paused":false,"scope":null,"reason":null}
```
