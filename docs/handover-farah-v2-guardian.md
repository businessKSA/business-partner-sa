## 1) المهمة والصلاحيات والأدوات
- **المهمة:** (أ) إصلاح فرح (المساعدة التنفيذية على n8n Azure) لتتذكر سياق الحديث وتفهم الردود المقتبسة، ولا تدفع لواتساب باهر إلا المال والعملاء، وتجهّز مسودات ردود بأسلوبه عبر Safe Send. (ب) وكيل «حارس الموقع»: مراقبة 24/7 للموقع الحيّ ورحلة العميل. (ج) دمج توجيهات مازن (معرفة الفريق، قالب البريد، التفويض، المنهجية، الهدف) في سياق فرح v2 كنص فقط.
- **الصلاحيات:** كتابة على فرع العمل `claude/intelligent-agents-collaboration-y788ck` (PR #352). تعديل n8n Azure لما بُني كنسخ غير فعّالة، وفعّلتُ مؤقتاً نسخ الاختبار بإذن باهر الصريح ثم أعدتُها. لا تغيير على فرح الحيّة، لا إرسال لعميل، لا نشر، لا دفع. النشر والأوامر الإنتاجية من `az` للجلسة الرئيسية فقط.
- **الأدوات:** shell وgit، Postgres محلي ومشغّل n8n محلي (`ops/azure-n8n/n8n-localrun.mjs`)، واجهة n8n Azure REST بمفتاح للقراءة/الكتابة، Playwright، `az` لوظيفة حاوية الحارس. Azure OpenAI النشر `bp-main` فقط. أدوات Notion وn8n MCP وGitHub MCP كانت منقطعة في أغلب الجلسة، ولا أصل إلى Notion الآن.
