الموقع: Vercel → Static Web Apps، وهذا يلغي `vercel.json` بكل قواعده
(ومنها `ignoreCommand` الذي يحمي سقف النشرات). **لا تبدأ قبل استقرار ١ و٢.**

## قاعدة الهجرة: لا توقّف ولا فقد بيانات

ابنِ الجديد على أزور والقديم يعمل → انسخ البيانات → اربط → اختبر →
شغّل الاثنين معاً → حوّل جزءاً صغيراً من الاستخدام → راقب → زِد تدريجياً →
حوّل بالكامل → **أبقِ خطة رجوع** → أغلق القديم آخر شيء وبعد تأكد.

## قواعد لا تُكسر

- **المفتاح لا يُكتب في مستودع ولا في نوشن ولا في محادثة.** مكانه متغيّرات
  بيئة Vercel واعتمادات n8n. وعند بناء Key Vault يصير هو المصدر.
- n8n Cloud يمنع `$env` في التعبيرات — أي مفتاح هناك يكون في اعتماد لا تعبير.
- لا تُعِد أي مزوّد غير أزور إلى `api/`.
- الدليل على «تم» هو فحص حيّ بعد النشر، لا كود مكتوب.

## ملاحظة للجلسات القادمة

جلسات Claude Code في الحاوية السحابية **لا تصل إلى أزور**: `az` غير مثبّت،
و`management.azure.com` محجوب بسياسة شبكة البيئة، ولا توجد متغيّرات أزور
في البيئة. أي عمل يحتاج إنشاء موارد أزور يُنفَّذ إما من جهاز المالك بعد
`az login`، أو بعد توسيع سياسة الشبكة وإضافة اعتماد للبيئة.
