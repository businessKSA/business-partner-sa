# الانتقال إلى Azure — الحالة والمتغيّرات

قرار المالك (2026-09-15): البنية التحتية الرقمية على Microsoft Azure، ولا
يُستعمل مزوّد آخر — باستثناء واحد صريح: **الدفع والفوترة الضريبية** (مُيسّر
وتمارا والدفترة) يبقى كما هو، لأن تحصيل الأموال يحتاج مزوّد خدمات دفع مرخّصاً،
وإصدار الفاتورة الضريبية يحتاج نظاماً مربوطاً بمنصة فاتورة (زاتكا). ولا تقدّم
أزور أياً من الاثنين.

الترتيب المعتمد: **الذكاء والبريد أولاً**، ثم البيانات، ثم الاستضافة.

---

## المرحلة الأولى — تمّت في الكود

### الذكاء: Azure OpenAI

كل نداء نموذج يمرّ بـ`api/_ai.js` وحده. أُزيلت سلسلة المزوّدين الأربعة
(جيميني، جروك، أوبن إيه آي، أنثروبيك) ووكيل n8n الاحتياطي.

| المتغيّر | إلزامي | المعنى |
|---|---|---|
| `AZURE_OPENAI_ENDPOINT` | نعم | `https://<الاسم>.openai.azure.com` بلا شرطة أخيرة |
| `AZURE_OPENAI_API_KEY` | نعم | مفتاح المورد |
| `AZURE_OPENAI_DEPLOYMENT` | نعم | **اسم النشر** لا اسم النموذج — هو ما يُنادى في المسار |
| `AZURE_OPENAI_VISION_DEPLOYMENT` | لا | نشر قادر على الصور؛ الافتراضي هو النشر نفسه |
| `AZURE_OPENAI_API_VERSION` | لا | الافتراضي `2024-12-01` |

المواضع التي تبدّلت: `api/chat.js` (المستشار ومساعد الإدارة)،
`api/hire.js` و`api/candidate.js` (التوظيف)، `api/_docread.js` (قراءة
المستندات)، و`quotes/src/lib/agent.ts` (الوكيل المولِّد للعرض والعقد).

### البريد: Azure Communication Services

كل إرسال يمرّ بـ`api/_mail.js` وحده. كان نداء Resend مكرراً نصّاً في خمسة عشر
موضعاً عبر أحد عشر ملفاً.

| المتغيّر | إلزامي | المعنى |
|---|---|---|
| `ACS_CONNECTION_STRING` | نعم* | سلسلة الاتصال كما تعطيها اللوحة |
| `ACS_ENDPOINT` + `ACS_ACCESS_KEY` | نعم* | بديل مفرّق لمن يفضّل Key Vault لكل قيمة |
| `ACS_SENDER_ADDRESS` | نعم | من نطاق مُتحقَّق منه في أزور، مثل `Business Partner <DoNotReply@businesspartner.sa>` |
| `ACS_API_VERSION` | لا | الافتراضي `2023-03-31` |

\* إمّا سلسلة الاتصال وإمّا المفرّقان.

قبل أول إرسال: أضِف النطاق في مورد Email Communication Services وأكمل
تحقّق SPF وDKIM، وإلا رُدَّت الرسائل. التوقيع مُختبَر في
`tests/azure-mail.test.mjs`.

## ما لم ينتقل بعد، ولماذا

| البند | الحالة | ما يلزم |
|---|---|---|
| قراءة ملفات PDF | **متوقّفة مؤقتاً** | رؤية Azure OpenAI تقبل الصور لا الـPDF. يُردّ الآن خطأ `pdf_needs_document_intelligence` باسمه بدل فشل غامض. الحل: تهيئة **Azure AI Document Intelligence** وربطها. قراءة الصور تعمل. |
| قائمة المشتركين | Resend | `RESEND_AUDIENCE_ID` في `book.js` و`requests.js` و`workspace.js` و`newsletter.js` — قائمة تخزين لا إرسال. تصير جدولاً عند نقل القاعدة إلى Azure Database for PostgreSQL. |
| الأتمتة (n8n) | n8n | تنتقل إلى Azure Logic Apps في مرحلة لاحقة. |
| المعلومات (نوشن) | نوشن | مصدر التأليف؛ الاسترجاع ينتقل إلى Azure AI Search لاحقاً. |
| قاعدة البيانات والتخزين | Supabase | المرحلة الثانية: Azure Database for PostgreSQL Flexible Server (مخطّط Prisma و`db/schema.sql` ينتقلان كما هما) وAzure Blob Storage. |
| الاستضافة | Vercel | المرحلة الثالثة. |
| الدفع والفوترة | مُيسّر وتمارا والدفترة | **استثناء دائم بقرار المالك.** |

## عطل قائم قبل هذا العمل

`api/` فيه **١٣ دالة والسقف ١٢** على خطة Vercel الحالية، فحارس البناء
(`site/scripts/verify-api.mjs`) يوقف البناء على `master` نفسه — قبل أي تعديل
هنا. يلزم دمج نقطتين أو رفع الخطة. ونقل الاستضافة إلى أزور في المرحلة الثالثة
يُسقط هذا السقف من أصله.
