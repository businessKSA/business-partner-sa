## 6) ثغرة صلاحيات في `/ar/portal` 🔴

الصفحة الحيّة تحمل في شيفرة المتصفح:

```
OWNER_EMAIL = '<بريد المالك>'
if (e.toLowerCase() === OWNER_EMAIL) { unlock('ALL'); return; }
```

**من يكتب بريد المالك في حقل الدخول يفتح الاثني عشر موظفاً بلا أي تحقّق.**
والبريد نفسه مكتوب في مصدر صفحة عامة، فهو معروف لمن يفتحها.

ودالّة الدخول بالجلسة الصحيحة (`unlockFromSession`) **معرَّفة ولا تُستدعى قط** —
كودٌ ميت. فالمسار الشرعي معطّل والمسار الالتفافي مفتوح.

### الجذر أعمق من الصفحة

الصفحة تنادي **n8n مباشرة من متصفح الزائر**:

```
N8N_BASE = 'https://businesspartnerai.app.n8n.cloud/webhook'
```

باثني عشر مساراً، واحد لكل موظف. هذه المسارات **عامة بلا مصادقة** — فمن يعرفها
يستدعيها بلا مرور بالصفحة أصلاً.

**النتيجة الدقيقة:** هذه **ثغرة تجاوز اشتراك** لا تسريب بيانات عملاء. لا بيانات
مكشوفة، لكن المنتج المدفوع متاح مجاناً لمن يعرف السطر.

**الإصلاح الحقيقي في n8n لا في الصفحة:** مصادقة على الـwebhooks. وحذف السطر من
الصفحة وحده يغلق الباب الظاهر ويترك الشباك مفتوحاً.

**لم أغيّره:** تعديل مسار صلاحيات على الإنتاج قرار المالك، وخطؤه يقفل المالك خارج
بوابته.

## 7) رحلة العميل — أين تنقطع

```
الرئيسية ✅ → الخدمة ✅ → الطلب ✅ → الدفع ✅
   → تسجيل الدخول ⚠️ (ثلاثة مداخل مختلفة)
   → بوابة العميل ❌ (تصميم منفصل كلياً)
   → المتابعة ❌ (أي بوابة؟)
```

الانقطاع يقع **بعد الدفع بالضبط** — أي في أكثر لحظة يكون فيها العميل قد دفع.

## 9) قواعد ملزمة من الآن

- كل صفحة لها **مشروع واحد** و**وكيل مالك واحد**.
- ممنوع مدخلان لنفس الوظيفة بلا سبب مكتوب هنا.
- ممنوع إضافة صفحة خارج نظام التصميم الموحّد.
- كل صفحة تُحذف أو تُخفى **تُسجَّل هنا** ولا تختفي بصمت.

## 10) ما لم يُفحص في هذا الجرد

- اللغات غير العربية (الإنجليزية والصينية وغيرها) — الجرد عربي فقط.
- الاتساق البصري التفصيلي (الخطوط، الأزرار، المسافات) — قيس هنا بوجود الترويسة
  الموحّدة لا بمقارنة بصرية كاملة.
- سلوك الجوال و RTL على الصفحات الـ145 — لم يُختبر صفحةً صفحة.
- الصفحات المولّدة قد تختلف عن المحفوظة، لأن Vercel يعيد البناء عند النشر.
  الصفحات الثلاث في القسم ٣ **فُحصت حيّة**، وبقية الأرقام من الملفات المحفوظة.
