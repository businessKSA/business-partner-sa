# صفحة العرض الخاصة بالعميل — `/offer/<token>`

فرع مخفيّ من الموقع الرسمي: لكل طلب عميل صفحة واحدة فيها العروض المطابِقة بالصور والمساحات والموقع على الخريطة.

## لماذا صفحة لا رسالة

الوساطة تعني عرضاً خاصاً بكل طلب لا نشرة عامة. صور ومساحات في رسالة واتساب تضيع بعد يومين، والمرفقات لا تُقرأ على الجوال. الرابط يبقى، ويُفتح من أي جهاز، ويبدو كموقع لا كرسالة.

## الاستخدام من n8n

**حفظ حزمة عرض** — يعيد الرابط الجاهز للإرسال:

```
POST https://www.businesspartner.sa/api/requests?__route=offer
x-ops-key: <OFFER_OPS_KEY>
content-type: application/json

{
  "client_name": "خالد محي الدين",
  "request_title": "أرض تجارية في الرياض، ٥٠٠–٨٠٠ م²",
  "offers": [
    {
      "title": "أرض تجارية — حي الياسمين",
      "area": 650, "city": "الرياض", "district": "الياسمين",
      "category": "أرض تجارية", "price": 2400000, "currency": "ريال",
      "facade": "شمالية ٢٠م", "age": "", "units": "", "status": "متاح",
      "notes": "على شارع تجاري.",
      "images": ["https://.../1.jpg"],
      "lat": 24.8221, "lng": 46.6391,
      "map_url": "https://www.google.com/maps?q=24.85,46.63"
    }
  ]
}
```

الرد: `{ "ok": true, "token": "…", "url": "https://www.businesspartner.sa/offer/…" }`

الحقول كلها اختيارية عدا `title` — الفارغ لا يُعرض أصلاً بدل أن يظهر سطراً فارغاً. والحزمة ليست خاصة بالعقار: `title` و`facts` تصلح لرخصة استثمار أو عمالة أو أي خدمة.

## الأمان

| الطبقة | السلوك |
|---|---|
| الكتابة | `OFFER_OPS_KEY` إلزامي. **بلا مفتاح مضبوط في البيئة تُغلق الكتابة تماماً** — افتراض آمن لا باب مفتوح |
| القراءة | الرمز وحده (٢٤ بايت عشوائية). العميل لا يملك حساباً ولن ينشئه ليرى عرضاً |
| الرمز | يُقيَّد بنمط `[A-Za-z0-9_-]{16,64}` قبل أن يبني اسم ملف — `../` مرفوض |
| الروابط | الصور والخرائط تُقبل `https:` فقط — `javascript:` حقنٌ حقيقي |
| الترويسات | `noindex, nofollow, noarchive` + `no-referrer` + `no-store` |

> ⚠️ **سرّية بالرابط لا مصادَقة.** لا تضع في الحزمة سعراً داخلياً ولا هامشاً ولا بيانات عميل آخر.

## محلياً

```bash
LOCAL_DB=1 OFFER_OPS_KEY=test-ops npm run dev
```
ثم `http://localhost:3000/offer/<token>`.

خادم التطوير صار يطبّق تحويلات المسارات العامة لا `/api/` فقط — قبل ذلك كان `/offer/…` يعطي ٤٠٤ محلياً بينما يعمل على Vercel، وهي بالضبط الفجوة التي وُجد «التطوير المحلي أولاً» ليغلقها.

## ما تبقّى

توليد الحزمة من مطابقة الطلب بالعرض يحتاج ذكاءً لقراءة رسالة الواتساب واستخراج المساحة والموقع. محرّك المطابقة نفسه موجود: `RE — Matching Engine` (`1YRfOoXmUYLPExTg`).
