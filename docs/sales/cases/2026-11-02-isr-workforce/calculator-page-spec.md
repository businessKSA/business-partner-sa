# صفحة الآلة الحاسبة للتكاليف بناءً على الرواتب (طلب المالك 4/11)

الرابط المكتوب في عرض ISR: `www.businesspartner.sa/calculators/workforce-cost` — **صفحة غير موجودة بعد**، ولا يُرسل العرض قبل بنائها.

## المطلوب (يبنيه وكيل الموقع، لا بدر)
- صفحة في الموقع الجديد بقشرة `SV1.shell()`، ضمن `/calculators/`.
- المدخلات: الراتب الشهري، الجنسية (فلبينية/هندية/نيبالية)، مدة العقد (12 أو 24 شهراً)، مصنع أو لا، (اختياري) قرار توطين.
- المخرجات: السعر الشهري للعامل قبل الضريبة وبعدها، وتفصيل البنود الظاهرة للعميل فقط (بلا الأوفر هيد ولا رسومنا).
- الصيغة نفسها `worker_price(a, loc, factory, months)` في `docs/sales/cases/2026-11-02-isr-workforce/content.py`: الراتب + الحكومية + الطبي + المخصصات + 500 تكاليف إدارية وتشغيلية + رسومنا (10% وأدنى 500) + 900 توطين؛ المصنع ناقص 800.
- لا بدلات سكن/إعاشة/مواصلات في السعر (على العميل، أو 300 للبند لمن راتبه أقل من 3,000 إن اختار).

## الحاسبة الثانية: تكلفة الموظف السعودي
`www.businesspartner.sa/calculators/saudi-employee-cost` — لكل وظيفة سعودية مهنية وغير مهنية (مبيعات، تسويق، فني، مهندس…): الراتب → التأمينات على صاحب العمل والموظف + نهاية الخدمة + الإجازة = التكلفة الشهرية. الصيغة `saudi_one(m)` في `content.py`. الحدّ الأدنى للفني 5,500 وللمهندس 8,000 (قرارات التوطين).
