1. وسيط/مستشار عقاري: وكيل ذكاء اصطناعي للطلبات والتواصل مع الوسطاء.
2. مدرب ومستشار أعمال: منصة لبيع الخدمات مع تذكير بالدفع ودفع وتحصيل إلكتروني.
