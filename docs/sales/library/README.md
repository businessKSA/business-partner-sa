# مكتبة مستندات المبيعات — 200 خدمة × (عرض · عقد · عدم إفصاح · شروط · POC · تفويض)

طلب المالك 2026-11-03. **داخلية.** لا تُرسل منها شيئاً لعميل: ما يخرج للعميل PDF فقط وبعد «أرسلي» من المالك (brand-and-presentation-standard §7). ما هنا مصادر HTML مفتوحة.

## الفكرة
لا 1200 ملف يدوي. **مجموعة قوالب لكل فئة (9) + قالب عدم إفصاح مشترك + مولّد** (`generate.py`، بايثون قياسي) يملأ بيانات كل خدمة من `site/assets/data/catalog.json` بالرمز (SKU): الاسمان، الفئة، السعر أو `[●]`، الرسوم الحكومية المنفصلة، العرض المفصّل، المنصة الحكومية. القوالب نفسها ملفات HTML قابلة للقراءة والتعديل.

النصوص القانونية (نواة العقد، بنود الفئات، عدم الإفصاح، خطاب التفويض) **تُقرأ مباشرة** من `docs/sales/templates/categories/*` فتصل تعديلات عبدالعزيز بإعادة التوليد. نطاق كل فئة والمتطلبات والاستثناءات وملاحق التفويض والـPOC في `clauses.py`.

## التوليد
```
python3 generate.py templates            # القوالب + README الفئات
python3 generate.py index                # services-index.csv / .md (200 صفاً)
python3 generate.py build --sku BP-CHAMBER-01 [--discount 10|20|30] [--pdf]
python3 generate.py build --category "HR Services"   |   --all     # المخرجات في out/ (غير مُتتبَّعة)
python3 generate.py samples              # out-samples/: 3 خدمات لكل فئة
python3 generate.py verify               # التغطية والمحظورات
python3 generate.py check-fit            # اتساع الصفحات (يتطلب weasyprint)
python3 generate.py all
```
`--pdf` يستعمل WeasyPrint أو Chrome إن وُجد. **لم تُنتَج PDF هنا:** لا Chrome في البيئة، وWeasyPrint يبدّل الخطوط (لا IBM Plex) ويقصّ شعار الغلاف، فلا يصلح لنسخة عميل. تُنتَج PDF النهائية بـ Chrome بخطوط الهوية.

## القواعد المطبّقة
- السعر من الكتالوج بالرمز (SKU) + ضريبة 15%، وإلا `[●]`؛ لا خصم خارج 10/20/30 (`--discount` يرفض غيرها).
- الرسوم الحكومية منفصلة دائماً ولا يُذكر مبلغها.
- لا «مسودة» ولا «الوكيل»، لا اسم عميل، لا آيبان (`[IBAN]`)، لا هاتف ولا عنوان وطني (`[●]`)، لا هويات.
- خدمات المخالفات (BP-HRSD-04 وBP-HRSD-05 وBP-SELF-01): نطاق «مراجعة / دراسة أهلية المسار / تجهيز / تقديم / متابعة» بلا وعد بالإلغاء، ويُستبدل تلقائياً.
- لا وعد بنتيجة: بند «عدم ضمان النتيجة» في العقد والعرض.
- التفويض فقط حيث منصة أو إجراء جهة حكومية (حقل `govPlatform` أو `govFeesSeparate` أو استثناء مسجّل في `AUTH_OVERRIDE`).
- POC فقط لفئة الأتمتة والذكاء الاصطناعي وأي رمز في `TECH_EXTRA` (فارغة الآن).
- الفحص: `verify` يؤكد تغطية 200 رمزاً وتوليد 945 مستنداً بلا خطأ وخلو القوالب والعينات من المحظورات؛ و`check-fit` أكد أن لا صفحة تتجاوز منطقة المحتوى (فُحصت العينات وأطول خدمتين اسماً في كل فئة).

## قرارات تنتظر المالك
1. **العنوان الوطني على الورق الرسمي:** تعارض بين `RDAA9214` (قوالب REV) و«Al Arid · Office 25…» (المعيار) و`RHSC2978` (site.json). وُضع `[●]` حتى يحسمه. والجوال `[●]` كذلك.
2. **REV-* (6 باقات):** تستعمل قالبي REV المخصصين لا العام. وهل هي «منتج تقني» يحتاج POC؟ (`TECH_REVIEW`) — الافتراضي لا.
3. **20 خدمة بلا سعر في الكتالوج (`[●]`):** BP-REC-04 · BP-REC-05 · BP-RE-06 · BP-HOUSING-01/02 · AI-GEN · CF-GEN · GOV-GEN · GR-GEN · HR-GEN · PR-GEN · RE-GEN · REC-GEN · SBC-GEN · SUP-GEN · TR-GEN · MA-BRK · REV-START/TEAM/ENT. التسعير عند pricing لا عند المبيعات.
4. **جدول الدفع:** نسب الدفعات وأيامه `[●]` (لا قاعدة معتمدة غير الشهري مقدماً).
5. **سلّم الخصم 10/20/30 وحد الهامش** (BP-TPL-SAL-05): مفعّل في المولّد كقيد فقط؛ الاعتماد عند المالك.
6. **رسم POC:** لا سعر له في الكتالوج → `[●]`؛ وهل يُحسم من التنفيذ.
7. **بنود `[●]` أخرى في العقد:** مهلة الإلغاء، الرسم الأدنى غير المسترد، جداول الاسترداد (الإقامة المميزة والاستقدام)، ملكية حل الذكاء الاصطناعي وتكاليف الاستعمال وفترة الصيانة، مدة العقد، مدة الاحتفاظ بالبيانات.
8. كتابة اسم المالك بالإنجليزية «Baher Bakr Ali Magnas» بحاجة لتأكيده.
