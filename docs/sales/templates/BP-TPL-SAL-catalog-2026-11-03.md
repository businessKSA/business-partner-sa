# قائمة رموز نماذج المبيعات — BP-TPL-SAL (مسودة، 2026-11-03)

داخلية. جواباً على طلب مازن «مكتبة النماذج الموحدة». الترميز `BP-TPL-SAL-<رقم>-v<إصدار>`. لا بيانات عملاء حقيقية (متغيرات `{{...}}` فقط). الاعتماد بتعميد المالك.
المصدر الواحد بمتغيرات يولَّد منه DOCX وPDF: سارة تسلّم المعيار ومحمد المولّد. دوري هنا: تحديد المحتوى والمتغيرات والقواعد.
