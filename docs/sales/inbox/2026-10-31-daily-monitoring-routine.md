# روتين المراقبة اليومية للعملاء الواردين عبر الموقع (أمر المالك الدائم عبر بدر، 2026-10-31)

الفحص: مرة صباحاً يومياً على الأقل. قراءة فقط، لا إرسال.

## المصادر
1. إيميلات «عميل جديد/عائد دخل محادثة» وتنبيهات العملاء المحتملين.
2. «متابعات اليوم» (43–60 عميلاً) وإيميلات «[فرح]» و«طلب يحتاج مراجعة يدوية للمبلغ» (BP-234614، BP-440157، BP-693518، BP-598860، BP-567363) وطلبات المنصة Q- وRFQ-.
3. حجوزات BC-، وصفقات DL-، ونماذج التواصل والتذاكر.

## لكل عميل
1. صنّفه: خدمة / عقار / EOR / توظيف / مورّد.
2. وجّهه للفريق المناسب بسطر واحد (توظيف وEOR ← الموارد البشرية، عقار ← العقارات، مورّد ← المشتريات، عقود وعمولات ← القانونية والامتثال).
3. أرسل لملاك بريفاً للرد (لا أنشئ مسودات بنفسي).
4. سجّل الموعد في الدفتر.

## الحصيلة لبدر
كم جديد، كم أُحيل، ما تأخر.
