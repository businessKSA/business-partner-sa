# معيار مجلد العميل والترقيم الداخلي — مقترح (2026-10-30)

بطلب المالك: كل النسخ متوفرة في Drive داخل مجلد العميل واسم المشروع، وترقيم داخلي للخدمات والعملاء في Notion وAzure، والأتمتة تعمل دائماً. **مقترح بانتظار اعتماد المالك؛ لا يُطبَّق على الموجود قبل ذلك.**

## الترقيم
| الكيان | الصيغة | مثال | ملاحظة |
|---|---|---|---|
| العميل | `CL-0001` | CL-0007 | رقم دائم لا يتكرر، ولو تغيّر الاسم التجاري |
| الخدمة (فئة الكتالوج) | `SV-01` … `SV-11` | SV-11 = تطوير الأعمال | يطابق ترقيم مجلدات القوالب 01–11 |
| المشروع/الصفقة | `PRJ-2026-0001` | PRJ-2026-0012 | يربط العميل بالخدمة؛ ويُربط بـ`DEAL-…` القائم |
| الوثيقة | `<PRJ>-<النوع>-v<رقم>` | PRJ-2026-0012-AGR-v2 | الأنواع: QUO · AGR · NDA · POC · POA · SIGNED |

الأسماء التجارية للباقات (`REV-*`، `BP-PKG-*`) تبقى كما هي؛ هذا ترقيم داخلي للتتبع لا يُعرض للعميل إلا في أسماء الملفات.

## بنية Drive (مجلد باسم العميل، بالعربية إن كان إيميله عربياً)
```
<اسم العميل> (CL-0007)/
  <PRJ-2026-0012 — اسم المشروع>/
    01-عرض السعر Quotation   : PPTX + PDF
    02-العقد Agreement        : DOCX + PDF
    03-عدم الإفصاح NDA       : DOCX + PDF
    04-إثبات المفهوم PoC     : DOCX + PDF   (أتمتة وذكاء اصطناعي فقط)
    05-الوكالة POA           : DOCX + PDF   (تأسيس خارجي فقط)
    06-الموقَّع Signed        : PDF + شهادة DocuSign (يملؤه n8n)
    00-سجل النسخ والمفاوضات  : ملف نصي
```
- كل نسخة تُحفظ بصيغتها: DOCX للعقد وNDA وPoC والوكالة، وسلايدز للعرض، وPDF لكل منها.
- الآيبان والجوال يظهران في النسخ النهائية فقط، ولا يُكتبان في أي قاعدة بيانات.
- المالك يفتح المجلد بـ«أي شخص لديه الرابط» يدوياً.

## Notion
- قاعدة العملاء: `CL-xxxx`، الاسم، الحالة، روابط Drive. (لا جوالات ولا هويات.)
- قاعدة المشاريع: `PRJ-…`، العميل، الخدمة `SV-xx`، المرحلة، السعر المعتمد، حالة كل وثيقة، رابط المجلد، رقم `DEAL-…`.
- صفحة الكتالوج: عمود «رمز الخدمة SV-xx».

## Azure (يحتاج وكيل المنصة)
- قيد: لا بيانات شخصية. المطلوب منه تحديد أين يُسجَّل الترقيم والحالة (قاعدة أو جدول)، وتأمين أسرار الآيبان وDocuSign. لا أفترض بنية Azure الحالية.

## الأتمتة الدائمة
- n8n: عند قبول العميل → إنشاء مجلد المشروع بالبنية أعلاه → رفع كل النسخ → إنشاء المظروف بالحارس → تحديث Notion وفرح → رفع الموقَّع إلى `06-Signed`.
- مراقب يومي: ينبّه فرح إن تعطل أي سير (لا مظروف عالق، لا مجلد ناقص، لا صف بلا رقم).

## ما يحتاج قرار المالك
1. اعتماد صيغ الترقيم أعلاه.
2. هل يُرقَّم العملاء الحاليون الآن (CL-0001…) بالتسلسل حسب تاريخ الدخول؟
