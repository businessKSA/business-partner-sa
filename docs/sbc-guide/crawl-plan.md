# خطة القراءة — ما يقرؤه المالك بـClaude in Chrome

المواقع الحكومية تحجب السحابة؛ القراءة تتم من متصفح المالك ويسلّمها المدير لوكيل `sbc-guide`.
**لا نموذج يُفتح أو يُرسل، ولا بيانات شخصية تُدخل.** المطلوب نصّ ظاهر + رابط الصفحة + تاريخ القراءة.

## المرحلة ١ — خريطة الموقع (`scbc.gov.sa/ar/guidelines`)
| التبويب | ما يُقرأ (قائمة فقط) | الناتج |
|---|---|---|
| رحلة المستثمر | عناوين القطاعات وروابطها | أسماء + روابط |
| إجراءات الخدمات | قائمة الجهات وأسماء الخدمات تحت كل جهة + عدّادها | جهة ← خدمات + رابط كل خدمة |
| الأنظمة والتشريعات | أسماء الأنظمة وروابطها | قائمة |
| دليل المكاتب المعتمدة | أصناف المكاتب وروابط القوائم | أصناف + روابط |
| خدمات الاعتراضات | أنواع الاعتراض وروابطها | قائمة |
| دليل المخالفات | أصناف المخالفات وروابطها | قائمة |

## المرحلة ٢ — التفاصيل صفحة صفحة (لكل خدمة/إجراء)
| الحقل المطلوب | ملاحظة |
|---|---|
| الجهة والمنصة المنفذة | كما تظهر |
| الخطوات | بالترتيب |
| المستندات المطلوبة | قائمة |
| الرسم الحكومي | رقم وحدة؛ أو «غير مذكور» |
| المدة | كما تظهر |
| الرابط الرسمي + تاريخ القراءة | إلزامي |

الترتيب المقترح: الجهات الأكثر طلباً أولاً، ودفعات من ١٠ خدمات لتُراجَع قبل المتابعة.
بعد كل دفعة يلخّصها `sbc-guide` بصياغتنا ويضع `status: needs_verification` حتى يعتمدها المالك.
