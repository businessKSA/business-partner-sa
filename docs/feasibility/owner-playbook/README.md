# خبرة المالك الميدانية

هنا تُحفظ أرقام وتجارب المالك الفعلية لكل قطاع دخله وخرج منه، في ملف لكل قطاع
(`logistics.md` …). كل سطر موسوم **«ميداني»** وبتاريخه.

الفريق يقرأ هذا المجلد **أولاً** ويقدّمه على أي مصدر آخر عند التعارض.

ما يُسجَّل لكل قطاع: كيف دخلتَ (المدخل) · كم كلّف فعلاً · الأخطاء · هوامش الربح الحقيقية ·
رواتب وتكاليف المناديب/الموظفين الفعلية · مدة الوصول للربح · كيف خرجتَ (المخرج: شراكة،
استحواذ، بيع حصة) وبأي شروط.

> لا يوجد ملف قطاع بعد. أول ملف مطلوب: `logistics.md`.
