## rasan.md — نشرة تكميلية: شركة رسن لتقنية المعلومات (طرح 2024)
المصدر: نشرة الإصدار التكميلية بتاريخ 2024-05-26 (تكمل الأولية بتاريخ 2024-03-25). **هذه نشرة تعديلات لا النشرة الكاملة** — دراسة السوق في الأولية، وهي مطلوبة.
- الهيكل: مدير الاكتتاب والمستشارون الماليون السعودي الفرنسي كابيتال ومورغان ستانلي السعودية؛ مستشار دراسة السوق والعناية المالية PwC؛ المراجع EY؛ مستشار قانوني Latham & Watkins؛ الجهات المستلمة البنك السعودي الفرنسي ومصرف الراجحي.
- رأس المال قبل الطرح 70.5 مليون ريال (سهم بريال)، وبعد الطرح نحو 75.8 مليون.
- أعداد الموظفين: 110 (2020) ← 121 (2021) ← 178 (2022). تكاليف العمالة: 11.2 ← 12.4 ← 28.1 مليون ريال (القفزة الأخيرة من زيادة العدد ومكافآت 6.7 مليون).
- إيراد تأمين السيارات 2022: 99.7 مليون ريال بنمو 57.4٪، وعدد الوثائق 2.3 ← 2.7 مليون وثيقة.
- أهميتها: مقارنة مباشرة مع إنشورا (وسيط/مقارنة تأمين إلكتروني)، ومثال على شكل مذكرة الطرح الذي يُستخرج منه الفريق.
