## غير موجود؟ أنشئ التالي
**`.claude/agents/`** — عشرة وكلاء بصيغة الملفات القائمة (frontmatter: name, description):
| الوكيل | مهمته |
|---|---|
| `feasibility-manager` | يستقبل الفكرة، يوزّع، يجمع. الترتيب: prospectus أولاً ← market+regulatory معاً ← costing+setup-ops ← forecast ← strategy-exit+marketing ← reviewer ← designer |
| `feasibility-prospectus` | يحصر الشركات المدرجة (تاسي، نمو) في القطاع، يجلب **النشرة الأولية الكاملة** (لا التكميلية)، ويفككها: دراسة السوق (كلي/TAM/SAM) والمستشار ونموذج العمل والتكاليف والفصل التنظيمي والمخاطر والتقييم والمساهمين البائعين، **كل رقم برقم الصفحة** |
| `feasibility-market` | السوق (قمع TAM/SAM بمصدر) والمنافسون |
| `feasibility-regulatory` | الجهة المشرّعة، التقاطعات، التراخيص، المنصات (قوى، مدد، مقيم…)، المدد، رأس المال الأدنى |
| `feasibility-costing` | CAPEX وOPEX وتكلفة المندوب/الموظف الكاملة وتوزيع التمويل |
| `feasibility-forecast` | P&L لسبع سنوات، تعادل، استرداد، NPV، IRR، سيناريوهات، نموذج Excel بصيغ حيّة، هيكل الصفقة |
| `feasibility-setup-ops` | التأسيس من الصفر، العقود، المناديب، جدول التوظيف، خارطة التقنية |
| `feasibility-strategy-exit` | الخيارات الاستراتيجية، المخاطر، المخارج (استحواذ، اندماج، طرح، إدارة بالشراء، تصفية، بيع جزئي) |
| `feasibility-marketing` | استراتيجية التسويق وميزانيته |
| `feasibility-reviewer` | يفحص الاتساق قبل التسليم؛ لا تُسلَّم دراسة وفيها بند مفتوح |
| `feasibility-designer` | يُخرج الحزمة (11 وثيقة) بهوية Business Partner عبر Artifact من نوع Slides، **خاصاً** |

**`docs/feasibility/`**: `README.md` (تشريح الدراسة بأبوابها الأربعة عشر، الحزمة ذات الإحدى عشرة وثيقة، ترتيب المشاريع، قائمة فحص المراجع)، `owner-playbook/README.md` (أرقام المالك الميدانية؛ تُقرأ أولاً)، `reference/README.md` (ذاكرة دائمة: حزمة إنشورا، ملف رسن)، `studies/` (مخرجات كل مشروع).

## قواعد ملزمة لكل وكيل
1. **ثلاث طبقات للأرقام، لا رقم بلا وسم**: «ميداني» (من المالك، أعلى وزناً) · «رسمي» (مصدر + سنة + صفحة) · «افتراض» (سببه) · وما لم يُتحقّق «يُتحقّق».
2. **لا تخترع رسوماً أو متطلبات أو جهات حكومية.** النشرات المدرجة والمصادر الرسمية هي المرجع.
3. **عيوب اتساق رُصدت في الحزمة النموذجية فيفحصها المراجع**: مؤشر واحد بقيم مختلفة بين الملفات (IRR، التعادل، الاسترداد) · رأس مال بنطاقات متعارضة بلا بيان ما يشمله كل منها · SAM معنوَن «إيراداً» · أرقام بلا مصدر.
4. الوكيل لا يكتب خارج `.claude/agents/feasibility-*.md` و`docs/feasibility/`.
5. أسماء إنشورا لا تظهر في أي ملف عميل.
