# بوابة ذكاء `/compliance-solutions`

صفحة `/compliance-solutions` كانت تعتمد في المحادثة وقراءة الملفات على `claude.use('sample')` الخاصة بمنصة Claude، فخارجها تقول «المساعد الذكي متاح داخل صفحة Claude فقط». البديل مسارٌ على خادمنا يمرّر المحادثة والملفات إلى **Azure OpenAI وحده**، ومن وراء قفل لأنه نداء نموذج مدفوع.

- المسار: `POST /api/chat` بجسم `{"action":"compliance-ai", ...}` — لا دالة جديدة في `api/` (سقف الـ12).
- الكود: `api/_cs-ai.js`، ويُستدعى من أول `api/chat.js` بعد قراءة الجسم. الاختبارات: `tests/cs-ai.test.mjs`.

## العقد

```json
{ "action": "compliance-ai",
  "messages": [{"role":"user|assistant","content":"..."}],
  "system": "اختياري",
  "files": [{"name":"x.pdf","mime":"application/pdf|image/png|image/jpeg|image/webp","data":"<base64>"}],
  "json": false }
```

| الحدّ | القيمة | عند التجاوز |
|---|---|---|
| الرسائل | آخر 24 (ما قبلها يُقصّ) | — |
| طول الرسالة | 8000 حرف | 413 |
| طول `system` | 12000 حرف | 413 |
| الملفات | 6 ملفات، المجموع 3MB قبل الترميز (قيد Vercel؛ يُرفع على Azure) | 413 |
| نوع الملف | pdf, png, jpeg, webp فقط | 400 |

المفتاح: ترويسة `x-cs-key` أو الحقل `key` في الجسم. **باب المالك** يعمل بلا مفتاح: حقل `key` بمفتاح اللوحة (`PANEL_KEY`) أو حقل `ticket` بتذكرة نفاذ — كما في `mode:"admin"`.

## المتغيرات (تُضبط في بيئة الاستضافة فقط، لا قيم حقيقية هنا)

| المتغير | الغرض | الافتراضي |
|---|---|---|
| `CS_ACCESS_KEY` | مفتاح الصفحة. **غير مضبوط = المسار مقفل** (إلا لباب المالك) | — |
| `CS_AI_ENABLED` | `0` / `false` / `off` يوقف المسار كله | مفعّل |
| `CS_AI_DAILY_CALLS` | سقف النداءات اليومي لكل الزوار معاً (يوم الرياض) | 300 |
| `CS_AI_DAILY_FILE_MB` | سقف حجم الملفات اليومي (ميغابايت) | 150 |
| `CS_AI_RATE_MAX` | طلبات كل IP في 10 دقائق | 60 |
| `CS_AI_KEY_RATE_MAX` | طلبات كل مفتاح في 10 دقائق (المفتاح مشترك بين الزوار) | 120 |
| `AZURE_OPENAI_ENDPOINT` / `AZURE_OPENAI_KEY` | حساب Azure OpenAI | — |
| `AZURE_OPENAI_TEXT_DEPLOYMENT` / `AZURE_OPENAI_VISION_DEPLOYMENT` | نشر النص ونشر الصور | `AZURE_OPENAI_DEPLOYMENT` |
| `AZURE_OPENAI_*_2` | منطقة ثانية احتياطية (اختيارية) | — |
| `AZURE_DOCINTEL_ENDPOINT` / `AZURE_DOCINTEL_KEY` | قراءة الـPDF (Document Intelligence). **بلا هذين لا يُقرأ PDF** | — |

## كيف يضبطها المالك

1. ولّد مفتاحاً عشوائياً طويلاً (32 حرفاً فأكثر) وضعه في `CS_ACCESS_KEY` في بيئة الاستضافة (Vercel الآن، وAzure Container Apps بعد القطع)، ثم أعد النشر ليُقرأ.
2. سلّم المفتاح لمن يحتاجه فقط. تغييره يُبطل القديم فوراً.
3. لإيقاف طارئ: `CS_AI_ENABLED=0` ثم إعادة النشر. ولتشديد الاستهلاك: خفّض `CS_AI_DAILY_CALLS`.
4. المفتاح لا يوضع في ملفٍ في المستودع ولا في كود الصفحة المنشورة للعموم.

## ما الذي يحدث عند كل حالة

| الحالة | الرد | يُنادى Azure؟ |
|---|---|---|
| بلا مفتاح، أو مفتاح خاطئ، أو `CS_ACCESS_KEY` غير مضبوط | `401 {"ok":false,"error":"locked"}` (الرد واحد في الحالات الثلاث، فلا يُكشف إن كان المفتاح مضبوطاً) | لا |
| 20 محاولة مفتاح خاطئ من عنوان واحد في 10 دقائق | `429 rate` (حتى للمفتاح الصحيح من العنوان نفسه إلى أن تنتهي النافذة) | لا |
| `CS_AI_ENABLED=0` (لمن اجتاز القفل) | `503 ai_unavailable` | لا |
| Azure غير مضبوط | `503 ai_unavailable` | لا |
| جسم فاسد، نوع ملف غير مسموح، base64 فاسد، آخر رسالة ليست من المستخدم | `400 bad_request` | لا |
| تجاوز حدّ الحجم أو العدد | `413 too_large` | لا |
| تجاوز حدّ المعدّل (IP أو مفتاح) | `429 rate` | لا |
| تجاوز السقف اليومي (نداءات أو ملفات) | `402 budget` | لا |
| PDF والقارئ غير مضبوط، أو لم يُقرأ أي ملف | `503 ai_unavailable` مع `reason` | لا (ولا نداء نموذج) |
| فشل Azure أو ردّ فارغ | `503 ai_unavailable` | نعم (فشل) |
| نجاح | `200 {"ok":true,"reply":"..."}` (ومعه `skipped` إن تعذّر بعض الملفات) | نعم |

الحواجز تُفحص بهذا الترتيب: القفل ← الإيقاف ← Azure ← الشكل والحجم ← المعدّل ← السقف اليومي. غير المصرَّح لا يرى حالة الخدمة (القفل قبل الإيقاف).

## كيف يُحسب السقف والمعدّل

- **المعدّل** عدّاد في ذاكرة النسخة (كما في `api/_eor.js` و`api/_aiws.js`) — مع تعدّد النسخ يتضاعف عملياً، ولذلك السقف اليومي هو الحاجز الحقيقي.
- **السقف اليومي**: كل نداء مقبول يُسجَّل في `audit_logs` (`action = cs.ai`) **قبل** نداء Azure، ويُعدّ منها لكل النسخ، مع عدّاد ذاكرة يعمل إن صمتت القاعدة (فتعذّر القاعدة لا يفتح السقف). اليوم بتوقيت الرياض.
- السجلّ: بصمة مقطوعة للمفتاح وأعداد (ملفات، بايتات، أحرف) فقط — لا المفتاح ولا نص المستخدم ولا محتوى الملفات ولا عنوان الـIP. ولا شيء من ذلك يُطبع في السجلات.

## قيود يعرفها المالك

- **حدّ جسم Vercel 4.5MB**: ملفات الـ6MB لن تصل من خلال Vercel (الجسم base64 أكبر بثلثٍ من الملفات). الحدّ الفعلي هناك نحو 3MB من الملفات؛ على Azure Container Apps لا يوجد هذا القيد.
- **المفتاح مشترك** بين كل من تعطيهم الرابط، فحدّ `CS_AI_KEY_RATE_MAX` (120 في 10 دقائق) يُقسَّم بينهم جميعاً. ارفعه إن صار أكثر من شخص يستعملها معاً.
- **حدّ الأخطاء لكل IP** قد يحجب موظفين خلف عنوان واحد (شبكة المكتب) عشر دقائق إن أخطأ أحدهم في المفتاح عشرين مرة.
- **أوقات الاستجابة**: مهلة الدالة 60 ثانية؛ قراءة PDF كبير ثم النموذج قد تقترب منها.
