# Azure فقط — جرد كل ما يُحاسَب خارج Azure وخطة إنهائه (قرار المالك 2026-10-16)

> «ابغاك تتأكد أن كل شيء على Azure وأن n8n على Azure ومافي استخدام رصيد لأي شيء خارج Azure.»

هذا جرد من الكود (`api/`، `n8n/`، `ops/`) لا من لوحات الحسابات؛ يُؤكَّد الاستعمال الفعلي والفاتورة من اللوحات.
الأسرار لا تُكتب هنا: أسماء المتغيّرات فقط.

## القاعدة

لا خدمة جديدة خارج Azure تُضاف ولا تُفعَّل. ما بُني على مزوّد خارجي يبقى إلى أن يُنقل بأمر المالك، ويُسجَّل هنا.
ما لا بديل له في Azure (بوابات دفع، توقيع إلكتروني، جهات حكومية) ليس «رصيداً» نستهلكه بل خدمة تُدفع عمولتها عند الاستعمال — يُقرَّر فيها المالك.

## ما يُنفَّذ بالترتيب (كلٌّ بإذن المالك)

1. **تأكيد حالة n8n**: تشغيل `az containerapp list -g bp-ai -o table` ثم قرار نقل السيناريوهات إلى n8n على Azure واستبدال خطّاف نشر الكتالوج الذي يشير إلى Vercel.
2. **قاعدة البيانات**: نقل Supabase إلى Azure PostgreSQL (نسخ ثم تحقق ثم تبديل `DB_DRIVER`) — يوم القطع أو قبله بإذن.
3. **البريد**: التحويل إلى ACS Email بعد توثيق النطاق (SPF/DKIM) وإصلاح سجلّ Resend الحالي أو التخلي عنه.
4. **مفاتيح الذكاء الخارجية**: جرد كل مفتاح غير Azure في Vercel/Container App وتعطيله بعد التأكد أن مسار Azure يغطي استعماله.
5. **Vercel**: بعد القطع يُحذف المشروع من اللوحة (يفعل المالك) ويُحدَّث CLAUDE.md §1.

## ما لا يدخل هذا القرار (يحتاج قراراً صريحاً من المالك)

Notion · مُيسّر · تمارا · الدفترة · DocuSign · نفاذ · واتساب · Google: لا بديل لها داخل Azure أو تعطيلها يعطّل عملاً قائماً.
