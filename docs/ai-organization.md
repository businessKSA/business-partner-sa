# منظمة الوكلاء الأذكياء — الهيكل وسجلّ المسؤوليات

قرار المالك (2026-09-23): **باهر لا يدير الوكلاء واحداً واحداً. باهر يدير
المدير التنفيذي الذكي، والمدير يدير المنظمة.**

هذا الملف هو **مصدر الحقيقة** لمن يعمل ومن يتوقف ومن المسؤول عن ماذا.
لا يُعتمد على سجلّ المحادثات — المحادثة تُضغط وتضيع، والملف يبقى.

## 4) الصلاحيات — من يقرر ماذا

### 🟢 أخضر — ينفّذ الوكيل مباشرة بلا سؤال

حذف حسابات · نقل ملكية · صلاحيات حسّاسة · **أي أمر تعاقدي أو حكومي** ·
**أي إرسال أو نشر باسم العلامة**

## 5) التصعيد

```
وكيل متخصص → مدير الإدارة → المدير التنفيذي → باهر
```

لا يتجاوز وكيل مديره إلا في طارئ. ولا يصل باهر إلا إذا:

- فشل الوكيل بعد ثلاث محاولات (إصلاح ← بديل ← احتياطي)
- احتمال فقد بيانات
- توقّف في الإنتاج
- حادث أمني
- تكلفة غير معتادة
- **قرار عمل لا قرار تقني**

ما عدا ذلك: يُصلَح ويُسجَّل ولا يُرسَل.

---

## 6) قواعد إعادة المحاولة

| المحاولة | التصرّف |
|---|---|
| ١ | الإصلاح المباشر |
| ٢ | حلّ بديل |
| ٣ | مسار احتياطي |
| بعدها | `BLOCKED` + سطر واحد يشرح سبب التوقّف |

لا توقّف من أول خطأ.

---

## 7) حالات المهمة

`NOT STARTED` → `IN PROGRESS` → `TESTING` → `DONE` → `MONITORING`
وعند التعثّر: `BLOCKED` بسبب مكتوب.

وفي الطابور: `NEW` → `QUEUED` → `PROCESSING` → `TESTING` → `DONE`،
وعند الفشل: `FAILED` → `RETRY` → `PROCESSING`.

## 8) لماذا لا تعمل هذه المنظمة اليوم

سبب واحد صريح: **لا يوجد تشغيل مستمر.**

الوكلاء اليوم يعيشون داخل محادثة. تُغلق المحادثة فيتوقف كل شيء، ولا طابور يحفظ
المهمة، ولا ذاكرة طويلة المدى خارج الملفات، ولا نبض يكتشف التوقّف.

### ما يلزم لتشغيلها فعلاً — بأبسط خدمة تكفي

| الحاجة | الخدمة | لماذا هذه لا غيرها |
|---|---|---|
| تشغيل ٢٤/٧ | **Azure Container Apps** | تكفي ولا تحتاج Kubernetes |
| طابور المهام | **Azure Service Bus** | المهمة لا تضيع بتوقّف الوكيل |
| ذاكرة طويلة | **Azure PostgreSQL** | بعد المرحلة ٤ |
| ملفات | **Azure Blob Storage** | الكود جاهز |
| سجلّات ونبض | **Application Insights** | يكشف الوكيل المتوقّف |
| الأسرار | **Azure Key Vault** | لا مفاتيح في كود ولا محادثة |

لا تُستخدم خدمة معقّدة متى كفت الأبسط. **Kubernetes غير مطلوب.**

### النبض (Heartbeat)

كل وكيل يعمل ٢٤/٧ يفحص دورياً: هل هو حيّ · هل الطابور سليم · هل القاعدة موصولة ·
هل الواجهات تستجيب · هل من مهمة عالقة. يُصلح ما يستطيع، ويُنبّه فيما عجز عنه فقط.
