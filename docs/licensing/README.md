## القواعد (تلتزم بها كل وكلاء الفريق)

1. **هذا السجل هو المصدر، وهو تاريخ لا حقيقة دائمة.** اللوائح تتعدّل (لائحة
   التمويل 179/MFC صدرت 22/12/2025 وأبطلت أرقاماً كانت سارية). عمر السجل فوق
   90 يوماً = يُعاد التحقق قبل أي استعمال أمام عميل.
2. **`VERIFIED` وحده يُقال كحقيقة.** `UNVERIFIED` يُقال «لم يتأكد» مع ما يلزم
   للتأكد (الرابط الرسمي أو جهة السؤال).
3. **المسوّدة ليست نافذة.** مثال: تعديلات رأس المال المقترحة في
   `CMA_N_4054` (التعامل 20م/10م، الحفظ 20م) لم يُوجد لها إقرار.
4. **لا وعد بقبول ولا بمدة.** الصيغة: دراسة أهلية / تجهيز / تقديم / متابعة —
   والقرار للجهة المنظِّمة (CLAUDE.md §4). المدد المنشورة تُنقل كما نُشرت
   «حدّها الأقصى بعد اكتمال الملف».
5. **لا أسعار لخدماتنا هنا.** أسعارنا من الكتالوج بالـSKU.
6. **ليست استشارة قانونية.** كل مخرج للعميل يُراجَع قبل الإرسال.
7. **الحدود:** التأمين → هيئة التأمين (لم يُتحقق منها من موقعها)؛ شهادات
   المساهمات العقارية → الهيئة العامة للعقار؛ الأصول الرقمية والتمويل المفتوح
   عبر CMA: لا فئة ترخيص وُجدت (لا تعني أنها غير موجودة).
8. **تصحيح السجل:** يقترحه المتخصص برابط رسمي، ويكتبه `fintech-licensing` وحده.
