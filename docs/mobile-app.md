# تطبيق الجوال — Business Partner (iOS + Android)

أُنشئ 2026-10-15 بأمر المالك: «تطبيق أنزّله في آبل وأندرويد». المالك: وكيل `mobile-app`.

## ما هو
غلاف **Capacitor 8** يحمّل الموقع الجديد الحيّ (`https://businesspartner.sa/`) داخل تطبيق
أصلي. **كود واحد لكلا المتجرين**، والواجهة هي الموقع نفسه: أي تحسين في `/my` أو `/catalog` أو
`/cart` يصل التطبيق فوراً دون مراجعة متجر. (هذا يوافق قاعدة 2.6: التطوير في الجديد وحده.)

| الطبقة | الملف |
|---|---|
| الإعداد | `mobile/capacitor.config.json` — `appId: sa.businesspartner.app` |
| الإقلاع / بلا إنترنت | `mobile/www/index.html` · `mobile/www/offline.html` (عربي + إنجليزي) |
| الأيقونة والإقلاع | `mobile/scripts/make-assets.mjs` ← `mobile/resources/` ← `npm run assets` |
| الجسر الأصلي | `site/assets/js/app-bridge.js` (يعمل داخل التطبيق فقط) |
| المشروعان الأصليان | `mobile/android/` · `mobile/ios/` |
| الفحص | `cd mobile && npm run check` · `tests/mobile-app.test.mjs` |

### ما يضيفه الجسر داخل التطبيق
شريط تبويب سفلي (الرئيسية · الخدمات · المستشار · السلة · حسابي) بلغة الصفحة وشارة عدد السلة،
اهتزاز لمسي، زر الرجوع في Android، شريط «غير متصل»، رفع ودجتَي واتساب والدعم فوق الشريط،
وقسم «عن التطبيق» في `/my` (الشروط، التواصل، طلب الحذف، الإصدار) بديلاً عن الفوتر المخفي، ولافتة تفعيل الإشعارات في `/my` (مطفأة حتى تُهيَّأ Firebase/APNs). لا شريط في `/checkout`
(يغطي زر الدفع) ولا في `/ops`.

## ما تحقّق منه فعلاً (2026-10-15)
- `npm run build` ناجح (1500 صفحة)، والاختبارات تمرّ.
- **APK تجريبي بُني بنجاح** (6.4MB، الحزمة `sa.businesspartner.app`، target SDK 36، الأذونات: إنترنت
  واهتزاز وإشعارات فقط).
- الجسر جُرّب في Chromium بمحاكاة `window.Capacitor` على `/` `/catalog` `/cart` `/my` `/ar/my`:
  الشريط والتبويب النشط والبادئة `/ar/` صحيحة، **وفي المتصفح العادي لا أثر له إطلاقاً**.

## ما لم يتحقّق منه — بصراحة
- **لم يُشغَّل على جهاز أو محاكٍ** (لا KVM هنا): الغلاف والـWebView والإقلاع وصفحة عدم الاتصال
  لم تُرَ حيّة. أول تشغيل على جهاز حقيقي هو الاختبار الحقيقي.
- **iOS لم يُبنَ**: يحتاج macOS وXcode. المشروع مولَّد وأصوله جاهزة فقط.
- الإشعارات لم تُجرَّب (تحتاج Firebase وAPNs).

## ما يلزم من المالك (قرارات وتكاليف — لا أفعلها بنفسي)
1. **حساب مطوّر آبل** 99$/سنة، و**حساب جوجل بلاي** 25$ مرة واحدة (رسوم المتجرين، لا Azure).
2. **اعتماد الأيقونة**: مشتقّة من حرفي الشعار (B خفيفة + P عريضة) على الكحلي `#0B1B5A` لأن الشعار
   الرسمي نصّي بلا رمز مربّع. غيّر `make-assets.mjs` إن أردت رمزاً آخر.
3. **مفتاح التوقيع** لـAndroid (`.jks`) يُنشأ بيد المالك ويُحفظ خارج git — ضياعه يمنع تحديث التطبيق للأبد.
4. **من يبني iOS؟** (أ) جهاز Mac عند الفريق، (ب) CI على macOS (تكلفة دقائق)، (ج) خدمة بناء.
   لا يُفعَّل شيء مدفوع بلا إذنك.
5. **رابط سياسة الخصوصية** ونموذج «Data safety/Privacy labels» (يملأهما المالك).

## عوائق قبل الرفع إلى آبل
| العائق | الحالة |
|---|---|
| **حذف الحساب من داخل التطبيق** (إرشاد 5.1.1v) | ⚠️ زر «طلب حذف الحساب» في «عن التطبيق» يفتح واتساب برسالة جاهزة — **طلب لا حذف فعلي**. آبل قد ترفضه؛ المطلوب مسار خادم يحذف الحساب (`client-portal`) |
| **رابط سياسة الخصوصية** | ❌ لا صفحة خصوصية في الموقع (الشروط فقط). تحتاج نصاً قانونياً يكتبه `abdulaziz-legal` ثم يُوضع في `PRIVACY_PATH` داخل `app-bridge.js` فيظهر صفّها تلقائياً |
| **الحد الأدنى من الأصالة** (4.2) | ⚠️ الشريط واللمس وعدم الاتصال أصلية؛ الإشعارات تعزّزها — لا ضمان للقبول |
| الدفع | ✅ خدمات حقيقية تُستهلك خارج التطبيق → مُيسّر وتمارا مسموحان (3.1.3e) |
| Sign in with Apple | ✅ غير مطلوب (الدخول برمز بريد، لا دخول اجتماعي) |

## كيف تبني
```bash
cd mobile && npm ci
npm run check                 # فحص الإعداد
npm run assets                # أيقونات + إقلاع من الشعار
npm run android:debug         # APK تجريبي (Android SDK + Java 21)
npm run android:release       # AAB للمتجر — بعد وضع keystore.properties يدوياً
npm run ios                   # يفتح Xcode (macOS فقط)
```

## المرحلة الثانية (لم تُبنَ)
- تسجيل رمز الإشعار على الخادم وإرسال الإشعارات (من داخل دالة قائمة — سقف 12 دالة).
- بصمة/Face ID لفتح `/my`.
- روابط عميقة (`apple-app-site-association` و`assetlinks.json` تحت `/.well-known/` — تمسّ المنصة).
- تفعيل الإشعارات: ضع `google-services.json` و`GoogleService-Info.plist` ثم أضف `bp-push` إلى
  `appendUserAgent` في `capacitor.config.json`.
