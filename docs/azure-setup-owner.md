# تشغيل النظام على Azure — خطوات المالك

هذه الصفحة لك أنت، لا للمبرمجين. كل خطوة ضغطٌ على زر أو لصق نص.
بعد إتمامها يعمل كل شيء من نفسه.

**القاعدة:** لا يُطلب منك سرٌّ في محادثة. كل سرّ يُلصق في صفحة إعدادات مباشرة.

---

## لماذا لا يستطيع Claude فعل هذا عنك

Claude يتحكم في: المستودع (GitHub)، وn8n، وVercel.
**لا يملك مفاتيح Azure**، فلا يستطيع إنشاء موارد هناك. لهذا الخطوات الأولى
منك — مرة واحدة فقط — وبعدها يصير النشر زرّاً.

---

## الجزء ١ — لوحة الوكلاء (AI Space)

الهدف: صفحة القيادة تعمل خلف تسجيل دخول حقيقي بحسابك.

| # | الخطوة | أين |
|---|---|---|
| ١ | أنشئ مورد **Static Web App**: الخطة **Free**، المجموعة `bp-ai`، المصدر **Other** | portal.azure.com |
| ٢ | انسخ **Deployment token** من المورد | نفس الصفحة |
| ٣ | الصقه في سرّ باسم `AZURE_STATIC_WEB_APPS_API_TOKEN` | GitHub → Settings → Secrets → Actions |
| ٤ | الصق إعدادات اللوحة في سرّ باسم `AI_SPACE_CONFIG` | نفس المكان |
| ٥ | ادعُ نفسك بالدور `owner` | المورد → Role management |

بعدها ينشر السير `Deploy AI Space to Azure` نفسه تلقائياً.

---

## الجزء ٢ — فريق الوكلاء (يعملون ليل نهار)

الهدف: الوكلاء يعملون على Azure لا على n8n وحده، ولا يتوقفون بإغلاق جهازك.

أضف هذه الأسرار الأربعة في **نفس الصفحة** (GitHub → Settings → Secrets → Actions):

| اسم السرّ | من أين تجلبه |
|---|---|
| `AZURE_CREDENTIALS` | يُولَّد مرة واحدة — اطلب من Claude الأمر الجاهز |
| `AZURE_OPENAI_API_KEY` | مورد `bp-ai-ksa-2026` → Keys and Endpoint |
| `SUPABASE_URL` | لوحة Supabase → Project Settings → API |
| `SUPABASE_SERVICE_KEY` | نفس الصفحة (المفتاح السرّي) |

ثم: GitHub → **Actions** → `Deploy AI Agents to Azure` → **Run workflow** →
اكتب `deploy` → Run.

يظهر لك في نهاية التشغيل جدولٌ بالمهام التي صارت تعمل على Azure.

## الجزء ٣ — حماية المال (افعلها أولاً إن استطعت)

المنحة ١٠٠٬٠٠٠ دولار، لكن لها **مهلة تفعيل تنتهي مطلع ديسمبر ٢٠٢٦**،
والمنحة نفسها تنتهي ٨ سبتمبر ٢٠٢٨.

| # | الخطوة | لماذا |
|---|---|---|
| ١ | تأكد أن الاشتراك يحمل رصيد المنحة | Cost Management → Credits |
| ٢ | اضبط **Budget Alert** على مبلغ شهري | ينبّهك قبل أن يُصرف لا بعده |

## ماذا يحدث لو تأخرت

لا شيء ينكسر. النظام يعمل اليوم على n8n وVercel كما هو.
الأسرار الناقصة تجعل سيران النشر **يتخطّيان** بهدوء ولا يفشلان.

لكن يبقى خطران قائمان حتى تُنجز الجزء ١:

- لوحة التحكم داخل n8n محميّة بسرّية الرابط وحدها — من يملك الرابط يوقف الشركة.
- الوكلاء يعتمدون على موزّع واحد في n8n؛ توقُّفه يوقفهم جميعاً.
