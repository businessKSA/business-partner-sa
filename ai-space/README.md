# BP AI Command Space

اللوحة الحيّة لفريق Business Partner الذكي: باهر الافتراضي في المركز، والأقسام
تدور حوله، ومحادثة واحدة بالصوت والكتابة تصل إلى نفس نقطة النهاية.

تُستضاف على Vercel كمشروع مستقل، وn8n صار **واجهة بيانات فقط** بدل أن يولّد الصفحة.

## المنشور حاليًا

- المشروع على Vercel: `bp-ai-space` (`prj_YzzIBa8YOy9VATC24xiNsFWgAASa`)
- الرابط: https://bp-ai-space.vercel.app
- الحماية: **Vercel Authentication مفعّلة** على كل النشرات عدا النطاقات المخصّصة،
  فلا يفتحها إلا من هو داخل على حساب Vercel المالك.
- النشر تم بملفات مباشرة (`deploy_to_vercel`) لا من git، لأن `config.js` لا يدخل
  المستودع. لتحديث الصفحة: عدّل الملفات هنا، ثم أعد النشر بنفس اسم المشروع مع
  `config.js` الحقيقي.

## البنية

```
المتصفح (Vercel)                       n8n
  app.js ── GET  dataPath   ─────────▶ 🛰️ BP AI Space — Data API   (3B9PXV0YhcLOgMqi)
         │                              يقرأ ٦ جداول ويرجّع JSON واحد
         └─ POST chatPath   ─────────▶ 🧠 مُعين Chief of Staff      (YgRwn40v1CqsscJw)
                                        باهر الافتراضي يرد نصًا
```

- **الكلام والكتابة نفس المسار**: `ask()` واحدة، سواء جاء النص من `SpeechRecognition`
  أو من مربع الكتابة. لا يوجد Runtime ثانٍ ولا مستمع مكرّر.
- **الاستماع دائم لا زر ضغط**: `continuous = true` مع `interimResults`، ويتوقف
  الاستماع أثناء نطق الرد ثم يعود تلقائيًا.
- **النطق من المتصفح** عبر `speechSynthesis` — بلا أي خدمة مدفوعة.
- الرد المتوقّع: `VOICE: …` للنطق ثم `[[DETAILS]]` لما يُعرض على الشاشة؛
  إن لم يلتزم الرد بالشكل يُنطق أوله ويُعرض كاملًا.

## الملفات

| الملف | الدور |
|---|---|
| `index.html` | الهيكل: الشريط العلوي، الخريطة المدارية، السكك الجانبية، ملف القسم |
| `app.css` | التنسيق كاملًا (لا إطار خارجي) |
| `app.js` | تحميل البيانات، الرسم، ملف القسم، ومحرّك المحادثة الواحد |
| `config.example.js` | شكل الإعدادات — انسخه إلى `config.js` |
| `vercel.json` | استضافة ساكنة + `noindex` + إذن المايك |

## التشغيل محليًا

```bash
cp config.example.js config.js   # ثم ضع مسارات n8n الحقيقية
npx http-server . -p 8080 -s
```

المايك يحتاج `https` أو `localhost`؛ لن يعمل على `http://` من عنوان شبكة.

## الإعداد

`config.js` غير مُتتبَّع في git لأن هذا المستودع عام ومسارات الويبهوك أسرار بحد
ذاتها. الحقول في `config.example.js`:

| الحقل | المعنى |
|---|---|
| `n8n` | أصل النسخة، بلا `/` في آخره |
| `dataPath` | مسار GET الذي يرجّع `{agents,tasks,deals,kpis,campaigns,integrations}` |
| `chatPath` | مسار POST الذي يستقبل `{message,target_agent,source}` ويرجّع `{reply}` |
| `actionPath` | مسار أوامر التحكم (إيقاف/تشغيل/إنشاء مهمة) |
| `chatTimeoutMs` | مهلة المتصفح للرد (١٥٠٬٠٠٠ افتراضيًا) |
| `refreshMs` | تحديث اللوحة تلقائيًا (٤٥٬٠٠٠ افتراضيًا، و`0` يوقفه) |

## الحماية

الصفحة **مالكية**، ليست عامة: تُنشر خلف Vercel Authentication، وتحمل
`noindex, nofollow`. مسارات n8n لا تُكتب في المستودع.
