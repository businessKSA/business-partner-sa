# التحكم بالعين والصوت — دليل التشغيل

العين تحرّك المؤشّر وتختار بالتثبيت، والصوت ينفّذ ويكتب.

## التشغيل

**محلياً:** `npm run dev` ثم `http://localhost:3000/space/`
**المنشور:** لوحة AI Command Space على Azure Static Web Apps

اضغط **👁️ العين** في شريط المايك → اسمح بالكاميرا → عايِر مرة واحدة (خمس نقاط، ~١٠ ثوانٍ).

## كيف تختار

ثبّت نظرك على أي زر أو صفّ. حلقة زرقاء تمتلئ حول المؤشّر — عند اكتمالها (٩٠٠ مللي ثانية) يقع الاختيار. الهدف تحت نظرك مُعلَّم بإطار، فتعرف أين سيقع الاختيار **قبل** وقوعه.

حقول الكتابة لا تُنقر بل تُركَّز، فيبدأ الإملاء الصوتي فيها مباشرة.

## الأوامر الصوتية

| تقول | يحدث |
|---|---|
| «شغّل العين» | تشغيل |
| «أوقف العين» | إيقاف وإطفاء الكاميرا |
| «عاير العين» | إعادة المعايرة |
| «اختر» | اختيار فوري بلا انتظار التثبيت |

أي كلام آخر يذهب للمدراء كالمعتاد — الأوامر تُبتلع هنا ولا تُرسل، فلا تُستهلك توكنز على «شغّل العين».

## الخصوصية

المعالجة **كلها داخل المتصفّح** عبر MediaPipe. لا صورة تغادر الجهاز، ولا خادم يرى الكاميرا، ولا تكلفة ولا مفتاح — موافقٌ لقاعدة `CLAUDE.md §2.6`.

المعايرة تُحفظ في `localStorage` على الجهاز نفسه فقط.

## الضبط

في `config.js`:

```js
window.BP_EYE_CONFIG = {
  dwellMs: 900,   // أقصر = أسرع، وأكثر اختيارات خاطئة
  smooth: 0.25    // أعلى = أثبت وأبطأ استجابة
};
window.BP_EYE_DEBUG = true;   // سجل تشخيصي في الكونسول
```

## إن لم تعمل

`BPEye.diag()` في الكونسول يعطي الحالة كاملة.

| العرض | السبب |
|---|---|
| «رفضتَ إذن الكاميرا» | اسمح من قفل العنوان |
| «تعذّر تحميل محرّك التتبّع من أي مصدر» | الشبكة تحجب jsdelivr وunpkg |
| `secure: false` | افتح عبر `localhost` أو `https` — الكاميرا ممنوعة على `http` |
| المؤشّر يختفي | لا وجه في الكاميرا: الاختفاء متعمّد، فالتجميد يوهم أنه يعمل |
| الاختيار في غير مكانه | أعد المعايرة — تغيّر وضع الجلسة يُزيح التقدير |

## ما لم يُختبر

CDN المحرّك محجوب في بيئة التطوير، فتحميل النموذج **لم يُجرَّب هنا**. المُتحقَّق منه فعلياً: تحميل الوحدة، فتح الكاميرا (640×480)، ابتلاع الأوامر الصوتية، إطفاء الكاميرا عند الإيقاف، والمسارات المحلية. تتبّع النظر نفسه يحتاج وجهاً حقيقياً أمام كاميرا حقيقية.
