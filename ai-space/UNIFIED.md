# لوحة BP AI Space الموحّدة (AI Space + جارفس)

لوحة واحدة تجمع وظائف AI Space (خريطة الأقسام المدارية، المهام، الصفقات، جاهزية الربط، المحادثة بالصوت والكتابة، التحكم بالعين) مع خارطة جارفس (شبكة الفريق: فرح + ١٧ إدارة، النبض الحي، «يحتاجونك»، فحص فرح، صوت Azure Neural لكل مدير). لم تُحذف أي وظيفة قائمة.

> الحالة: **مبنية في المستودع ومُختبرة محلياً، غير منشورة.** النشر والأسرار قرار المالك (انظر أسفل).

## ما بُني

| الملف | الدور |
|---|---|
| `index.html` · `app.css` · `app.js` | اللوحة الأصلية، مع مفتاح عرض «مدار الأقسام / شبكة الفريق · جارفس» ولوحة «يحتاجونك» ونبض في الشريط العلوي |
| `jarvis.js` · `jarvis.css` | وحدة جارفس: الشبكة، النبض، يحتاجونك، فحص فرح، أصوات المدراء. مستقلة: لو سقطت بقي الأصل يعمل |
| `api/bp/` + `api/_lib/proxy.js` | دالة Azure Functions (Node 20، بلا اعتماديات) تمرّر الطلبات إلى n8n على Azure |
| `staticwebapp.config.json` | `/api/*` وكل شيء للدور `owner` فقط، و`/api` مستثنى من إعادة التوجيه إلى `index.html` |
| `dev-server.mjs` | تشغيل محلي ببيانات وهمية بلا Azure |
| `../tests/ai-space-api.test.mjs` | ١٨ اختباراً للوسيط والإعدادات ونظافة المستودع من الأسرار |

كل نداء من المتصفح صار `/api/bp/<op>`. العمليات: `data` · `pulse` · `health` · `chat` · `chatresult` · `voice` · `stt` · `action` · `minutes`.

## الأمان

- لا مسار ويبهوك ولا مفتاح ولا عنوان n8n في كود المتصفح أو المستودع (اختبار آلي يتحقق).
- الوصول: قاعدة `allowedRoles: ["owner"]` على الحافة، ثم تحقّق ثانٍ من الدور داخل الدالة من `x-ms-client-principal`.
- مفتاح فرح `X-BP-Farah-Key` يُضاف في الدالة فقط، ويُرسل فقط إلى n8n على Azure؛ لو وُجّهت عملية مؤقتاً إلى n8n Cloud عبر `BP_BASE_<OP>` لا يخرج المفتاح.
- أخطاء n8n تُختزل إلى رمز حالة؛ لا يصل المتصفح نصّ فيه مسار داخلي.
- `config.js` صار للمهل فقط (غير سرّي). سرّ `AI_SPACE_CONFIG` القديم **يُتجاهل** ويُستحسن حذفه.

## الأسرار المطلوبة من المالك (بالاسم فقط)

تُدخَل في **Azure Portal ← Static Web App ← Settings ← Environment variables** (ولا تُكتب في المحادثة):

| الإعداد | المعنى | يُستعمل في |
|---|---|---|
| `BP_N8N_BASE` | عنوان n8n على Azure Container Apps | كل العمليات |
| `BP_FARAH_KEY` | قيمة ترويسة `X-BP-Farah-Key` (اعتماد Header Auth v3) | chat · health · chatresult · action · minutes |
| `BP_PATH_CHAT` | مسار ويبهوك Command Space لفرح | المحادثة |
| `BP_PATH_HEALTH` | مسار فحص فرح | زر «فحص فرح» |
| `BP_PATH_PULSE` | مسار النبض | النبض و«يحتاجونك» |
| `BP_PATH_DATA` | مسار بيانات AI Space | الخريطة المدارية والمهام والصفقات |
| `BP_PATH_VOICE` | مسار نطق Azure Neural | الصوت |
| `BP_PATH_STT` | مسار تفريغ الصوت | الإملاء حين لا يعمل تعرّف المتصفح |
| `BP_PATH_ACTION` · `BP_PATH_MINUTES` · `BP_PATH_CHAT_RESULT` | اختيارية | أوامر التحكم · المحضر · الرد الطويل |
| `BP_BASE_<OP>` | اختياري: عنوان بديل لعملية واحدة (مثل `BP_BASE_PULSE`) أثناء الانتقال من Cloud | — |

المسارات تبدأ بـ`/` (مثل `/webhook/…`). عملية بلا إعداد تردّ ٥٠٣ باسم الإعداد الناقص، وتبقى الواجهة سليمة (الصوت يرجع لصوت المتصفح، النبض يعرض «غير مُعدّ»).

السرّ الوحيد المطلوب لسير النشر: `AZURE_STATIC_WEB_APPS_API_TOKEN`.

## كيف يُنشر (بعد موافقتك)

1. أنشئ Static Web App (الخطة المجانية تكفي للدوال المُدارة) وانسخ رمز النشر إلى سرّ GitHub `AZURE_STATIC_WEB_APPS_API_TOKEN`.
2. أدخل الإعدادات أعلاه في Azure Portal.
3. Role management ← Invite ← بريدك ← الدور `owner`.
4. دفعة تمسّ `ai-space/` على الفرع تشغّل `azure-ai-space.yml` (يتخطّى النشر بلا الرمز). لا علاقة له بـVercel ولا بسقف المئة نشرة.

## كيف تجرّبه محلياً الآن

```bash
node ai-space/dev-server.mjs      # http://localhost:4280 — بيانات وهمية، لا اتصال بأي خدمة
node --test tests/ai-space-api.test.mjs
```

لتجربته على n8n الحقيقي من جهازك: صدّر `BP_N8N_BASE` و`BP_PATH_*` و`BP_FARAH_KEY` في الطرفية ثم شغّل الأمر نفسه (الدخول مفتوح محلياً عبر `BP_LOCAL_ALLOW_ANON=1` الذي يضعه الخادم المحلي وحده؛ لا يُضبط في Azure أبداً).

## قيود معروفة

1. **مهلة ٤٥ ثانية**: أقصى مدة لطلب API في Static Web Apps. فرح تأخذ أحياناً أكثر (كانت مهلة المتصفح ١٥٠ ث). فوق ٤٢ ث يردّ الوسيط ٥٠٤ ورسالة واضحة. الجاهز جانب العميل: لو ردّ n8n بـ`{job_id}` تسأل الواجهة `chatresult` كل ٣ ث. يلزم سيران غير متزامنين على n8n Azure (انظر `docs/ai-space-n8n-azure-migration.md` §٣) — **لم يُبنيا ولم يُفعَّلا**. البديل: خطة Standard وربط Container App بدل الدوال المُدارة (تكلفة، قرارك).
2. **ما لم يُجرَّب هنا**: النشر الفعلي، تسجيل Entra، والاتصال بـn8n الحقيقي (الحاوية لا تصله). المُجرَّب: تحميل الصفحة في Chromium، مفتاح العرض، توجيه مدير، المحادثة والنبض و«يحتاجونك» وفحص فرح عبر الوسيط، واختبارات الوسيط.
3. وضع «جارفس» بلا يدين لم يُنقل لأن AI Space أصلاً يستمع باستمرار.
4. نسخة Vercel القديمة (`bp-ai-space`) لم تُمسّ.
