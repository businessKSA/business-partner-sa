# قيادة الـPR في هذا المستودع

1. **فحص Vercel الأحمر ليس عطلاً في الكود** عندما يكون سببه `api-deployments-free-per-day` أو تعطيل النشر للفرع عبر `git.deploymentEnabled` أو غياب مجلد Root (مثل `erp/` لمشروع bp-erp). لا تدفع كوميتاً لإعادة تشغيله، ولا تعلّق على الـPR أكثر من مرة واحدة عنه، ولا تنشئ تذكيراً لإعادة الفحص.
2. **لا دمج ولا موافقة** على أي PR. الدمج قرار المالك بكلمة «ادمجه».
3. **لا كوميت فارغ، لا إغلاق وإعادة فتح، لا Redeploy، لا deploy_to_vercel.**
4. تعليقات المراجعة الصغيرة تُنفَّذ وتُدفع بعد التحقق المحلي (`npm run build && npm test`). الكبيرة تُعرض على المالك.
5. تعارض الدمج مع `master`: ادمج master في فرعك، أعد التوليد بـ`npm run build`، لا تعدّل HTML المولَّد يدوياً.
6. اجمع التعديلات في دفعة واحدة؛ لا دفعات صغيرة متتابعة.
7. عند كل توقف حدّث صفحة الجلسة في قاعدة نوشن «🧭 سجل جلسات Claude Code» (انظر CLAUDE.md §5).
