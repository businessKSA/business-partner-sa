# فريق Business Partner الذكي — على Azure

باهر منسّقاً، وتحته مازن (العملاء) وبدر (المبيعات) وفرح (التسويق) ومحمد (الموقع).

## لماذا أُعيد بناؤه (2026-09-17)

كان الفريق على **Claude Managed Agents**، وهي خدمة مدفوعة من Anthropic —
تخالف قاعدة المالك ٢.٦ في `CLAUDE.md` (قرار 2026-09-15): *لا مدفوع خارج
Azure*. فأُعيد البناء على **Azure OpenAI** الذي تموّله منحة Microsoft for
Startups، وحُذفت الطبقة القديمة حتى لا يُشغّلها أحد سهواً.

وقبلها كان الفريق في **n8n**، وسقط لسبب بنيوي: أحد عشر مديراً يتقاسمون عقدة
محرّك واحدة، فماتت العقدة فتوقّف الجميع — وسير العمل يقول «نجح» وهو لم
يستدعِ أحداً. ما هنا في git: يُقرأ، ويُفحص نحوياً، ويُشغَّل محلياً قبل أن
يمسّ عميلاً.

## البنية

| الطبقة | أين |
|---|---|
| العقل | `azure/engine.mjs` — Azure OpenAI، نداء REST مباشر بلا تبعيات |
| الفريق | `azure/team.mjs` — باهر منسّقاً، والمتخصصون أدواتٍ يستدعيها |
| الأدوات | `azure/tools.mjs` — الكتالوج، الطلبات، الإرسال، بانتظار الموافقة |
| الشخصيات | `prompts/*.md` — كما هي، لم تتغيّر |
| الجولات | `azure/job.mjs` — `morning`, `site-check`, `weekly-content` |
| النشر | `azure/Dockerfile` + `azure/deploy.sh` — Container Apps **Jobs** |
| الحالة | Supabase عبر `api/_db.js` — قاعدة الموقع نفسها |

`n8n` لم يَعُد العقل ولا المنسّق: بقي **طبقة موصّلات** فقط (واتساب، LinkedIn،
Gmail) لأن تفويضات OAuth فيها تعمل، وإعادة بنائها أسابيع بلا عائد. وكل أداة
تُبنى هنا تُنقص الاعتماد عليه.

## الحوكمة — في الكود لا في البرومبت

البرومبت رجاء، والكود حاجز. `commitmentIn()` في `tools.mjs` يفحص كل رسالة
قبل الشبكة: أي رقم ريال، أو «السعر النهائي»، أو ضمان، أو خصم — **تُرفض
ولا تُرسل**، ويُطلب من الوكيل تسجيلها بـ`pending_approval` في جدول `tasks`.

الفحص نصّي متعمَّد البساطة: نموذج يقنع نفسه بأن جملته ليست التزاماً، وتعبير
نمطي لا يقتنع.

## التشغيل

```bash
cp agents/azure/.env.example agents/.env     # ثم املأ AZURE_OPENAI_*

# بروفة: لا رسالة تخرج، ولا قاعدة إنتاج تُمسّ
AGENTS_DRY_RUN=1 LOCAL_DB=1 node agents/azure/run.mjs "عميل يسأل عن تأسيس شركة"
AGENTS_DRY_RUN=1 LOCAL_DB=1 node agents/azure/job.mjs morning

# متخصص وحده
node agents/azure/run.mjs --agent mazen "راجع الطلبات التي لم تُتابَع"
```

`AGENTS_DRY_RUN=1` في أول تشغيل **دائماً**: الأدوات حقيقية وتمسّ عملاء.

## النشر

```bash
bash agents/azure/deploy.sh      # يُشغّله المالك، لا Claude — فيه إنشاء موارد
```

ينشئ ثلاث `Container Apps Jobs` بجداول cron بتوقيت UTC (الرياض +٣). الحاوية
تقلع، تعمل دقائق، وتنتهي — فلا يُدفع مقابل انتظار، و«لا ينامون» يصير رخيصاً
لأن الجدولة في السحابة لا في جهاز يُغلق غطاؤه.

## ما ينقص قبل أول تشغيل حقيقي

1. **`AZURE_OPENAI_DEPLOYMENT`** — من `ai.azure.com` ← Deployments ← عمود
   `Name`. **اسم النشر لا اسم الموديل**؛ الخلط بينهما يعطي
   `could not be found`، وقد أسقط محاولتين.
2. `AZURE_OPENAI_API_KEY` من نفس المورد.
3. `BP_N8N_BASE` و`BP_N8N_HOOK_KEY` — بدونهما يعمل كل شيء لكن الرسائل تُحاكى.
